# 풍월을 읊어라(Wax Poetic)

- **장르:** MOBA의 성장 시스템을 가미한 2D 탑뷰 RPG 게임
- **플랫폼:** PC
- **개발 기간:** 2025.10 ~ 현재
- **개발 인원:** 총 2명
- **개발 환경:** Unity 6.0, C#
- **프로젝트 상태:** 개발 중

## 1. 프로젝트 소개

고즈넉한 시골의 한 학교, 귀여운 강아지가 학생들의 귀여움을 받으며 살고 있습니다.
하지만 학생들을 폭력과 힘으로 억압하는 학교의 부당한 모습에 강아지는 분노합니다.
어느 날 신비로운 마법의 힘으로 두 다리로 서고, 인간의 말을 할 수 있게 된 강아지.
학생들에게 사랑받던 강아지는 이제 학생들을 폭력에서 구하기 위해 학교에 갑니다!
